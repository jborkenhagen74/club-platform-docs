# Current browser authentication example

Serve this directory through the same-origin HTTPS proxy as the host API. The example uses `/api/v1/auth/login`, `/auth/me` and `/auth/logout`, retains the bearer token only in memory and clears the password input after submission.

This is a minimal authentication example, not the full production portal. See [current API supplements](../../../docs/api/overview.md) and [historical person-list example](../web-basic-v2/README.md).
