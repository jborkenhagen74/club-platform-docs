# Screenshots und Prüfnachweise

Alle Bilder zeigen die echte Anwendung mit synthetischen Pilotdaten. Die Browserbilder verwenden deutsche UI-Texte. Dateiauswahl und Datumswähler können zusätzlich die Sprache des Browserbetriebssystems verwenden. Es wurden keine Oberflächen nachgezeichnet.

Die Ordner `desktop` und `mobile` bezeichnen Chromium-Browserprofile. Native Qt-Aufnahmen liegen getrennt unter `native`. Lange Seiten können durch Anklicken in Originalgröße gelesen werden; Dialogaufnahmen zeigen den sichtbaren Ausschnitt.
