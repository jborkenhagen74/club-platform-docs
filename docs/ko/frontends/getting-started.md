# 프런트엔드와 웹 서버 연동

[시작 페이지](../README.md) · [REST](../api/overview.md) · [설치](../installation.md)

포털은 React/TypeScript와 Tailwind 4를 사용합니다. `npm ci`는 잠금 파일을 따르고
`npm run build`는 정적 `dist/`를 생성합니다. PDF 코드와 폰트는 필요할 때
빌드 파일에서 읽으며 외부 CDN이 필수는 아닙니다. `examples/frontends/web-basic`은
로그인과 사람 목록만 보여주는 작은 예제입니다.

브라우저와 API를 동일한 HTTPS 출처에서 제공합니다. `/api/`를 루프백 호스트로
전달하고 `Host: 127.0.0.1:8080`을 설정하며 `Authorization`, `Origin`을 유지합니다.
`--portal-origin`에는 정확히 같은 출처를 지정합니다. 설정이 없으면 Origin이
있는 브라우저 요청은 거부됩니다. 올바른 설정 대신 와일드카드 허용을 사용하지 마십시오.

외부 상태 감시가 필요하면 `/health`를 별도로 설정합니다. `/api/` 프록시에는
이 경로가 포함되지 않습니다. 요청 본문, 비밀번호와 토큰을 로그에 남기지
않습니다. DNS, 인증서, 서비스 계정은 운영 절차로 관리하며 프로그램이
TLS 인증서를 자동 관리하지는 않습니다.

## 클라이언트 동작

토큰은 메모리에만 보관하고 URL·영구 저장소에는 쓰지 않습니다. `401`에서는
세션, 개인 목록과 초안을 지우고 재로그인을 요청합니다. `403`을 설명하고,
쓰기 중 네트워크 오류가 나면 재시도 전에 조회합니다. `409`는 현재 리비전을
비교한 뒤 처리합니다.

목록을 페이지별로 읽습니다. 참조는 `labels` 또는 연결 레코드의 이름으로
표시하되 저장에는 ID를 사용합니다. 응답 문자열을 HTML이 아닌 텍스트로 출력합니다.
파일은 사용자의 명시적 동작으로만 내려받습니다. 업로드 파일을 플러그인으로
실행하지 않습니다.

## 화면과 지원 범위

시스템 모드 외에 밝게, 어둡게, 숲, 자두색, 고대비 테마를 제공합니다. 날짜
표시는 지역 설정을 따르고 API는 ISO를 유지합니다. 작은 화면에서는 `Aktenbereich`로
기록 영역을 선택합니다. Core 사용자 정의 필드의 정의와 권한은 데스크톱에서
관리합니다. 계정과 자신의 회원 기록은 자동 연결되지 않습니다.

[OpenAPI](../../../openapi/club-platform.yaml)와 [필드 참조](../../../reference/resources.md)를
함께 사용하십시오. 예전 초안의 `/api/v1/appointments` 같은 없는 경로를 사용하면
안 됩니다. 제품 업데이트 전에 호환성을 시험하십시오.
