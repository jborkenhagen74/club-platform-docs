# 버전과 확인된 기능 범위

[시작 페이지](README.md)

기준: 애플리케이션 **0.5.0**, 커밋 `320a4c2709c13dd56455768a2f8819a815ad3997`,
스키마 **8**, 네이티브 ABI **2**, 문서 발행 **2026-09-09**.

| 계층 | 계약 |
|---|---|
| 제품 | 패키지 버전 0.5.0 |
| 데이터베이스 | 순서 있는 마이그레이션, 알 수 없거나 바뀐 정의 거부 |
| 확장 | ABI 2와 세 숫자로 구성된 별도 매니페스트 버전 |
| HTTP | `/api`, 별도 `/health`, 공개된 `/api/v1` 없음 |
| 문서 | de/en/fr/es/ko의 동일한 장 구성과 기능 범위 |

R1.9는 네이티브 호스트, R1.10은 무술 모듈, R1.11은 양식·PDF·CSV,
R1.12는 시범 운영 도구입니다. 시범 운영은 모든 OS의 서명 설치 프로그램이나
모든 대상 PC의 인수 완료를 뜻하지 않습니다. 번역 설명서로 화면 언어가 바뀌지 않습니다.

ABI 1과 `/api/v1`은 과거 초안입니다. 메뉴·뷰·REST 콜백은 0.5.0의 보장 기능이
아닙니다. 일정, 결제, 오프라인 동기화, 테넌트 격리, 자유로운 확장 UI, 자동
업데이트와 전체 화면 번역은 현재 범위 밖입니다. 제품, ABI와 실제 경로를 함께
확인하십시오.

변경 후에는 다섯 언어를 동기화하고 구현 기준을 갱신하며 문서 검증을 실행합니다.
식별자, JSON 키, URL과 명령 옵션은 번역하지 않습니다. 언어와 관계없이 보안
계약은 동일합니다.
