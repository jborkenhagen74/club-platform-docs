## 기본 개념

**인물(Person)**은 회원, 지도자, 연락 담당자 또는 후원자입니다. **사용자(User)**는
로그인 계정입니다. 두 기록은 별개이며 자동으로 연결되지 않습니다. 로그인 계정이
없는 사람도 관리할 수 있습니다.

**조직**은 도장, 스포츠 학교, 클럽, 협회 또는 기업을 나타냅니다. **회원 자격**은
인물과 조직을 연결하고 회원 번호, 상태, 가입 및 종료 날짜를 보관합니다.
**직책**은 조직 내 역할이며, **관계**는 그 밖의 지원·연락 관계입니다. 여러 조직에
소속되어 있다는 이유로 같은 인물을 중복 등록하지 마십시오.

인물 또는 조직의 상세 기록 화면에서 관련 정보를 탭별로 관리합니다. 탭을 바꾸어도
선택된 인물이나 조직은 유지됩니다. 조직 계층에서 상위에 있다는 이유로 다른 조직의
정보를 읽을 권한이 생기지는 않습니다.

## 로그인

1. 데스크톱 프로그램 또는 관리자가 제공한 HTTPS 포털 주소를 엽니다.
2. 데스크톱에서는 단독 실행 모드인지 서버 연결 모드인지 확인합니다. 두 데이터베이스에
   같은 이름이 있다고 해서 자동으로 동기화되는 것은 아닙니다.
3. 사용자 이름과 비밀번호를 입력하고 `Anmelden`을 누릅니다.
4. 예상한 인물 및 조직 목록이 표시되는지 확인합니다.

새 단독 실행 데이터베이스에서는 `Administrator einrichten`으로 최초 관리자를
설정할 수 있습니다. 동료 계정을 추가할 때 사용하는 일반 절차는 아닙니다. 서버
계정은 관리자가 준비합니다. 비밀번호는 최소 12자입니다. 로그인 실패가 반복되면
잠시 기다린 후 입력 정보를 확인하십시오.

포털 페이지를 새로 고치면 다시 로그인해야 합니다. 기본 세션은 최대 8시간, 미사용
시간은 30분입니다. 자리를 비우기 전에 저장하고 로그아웃하십시오. 브라우저가 열려
있는 것은 컴퓨터 잠금을 대신하지 않습니다. 데스크톱의
`Administration → Passwort ändern`에서 비밀번호를 변경할 수 있습니다.
현재 포털에는 별도의 비밀번호 변경 화면이 없습니다.

## 조직과 계층 구조

### 조직 등록

1. `Organisationen`에서 먼저 검색하여 중복 여부를 확인합니다.
2. `Neu anlegen`을 누르고 정식 명칭을 입력합니다.
3. 조직 유형을 선택합니다: `Dachverband`는 상위 협회, `Landesverband`는 지역 협회,
   `Verein`은 클럽, `Sportschule`은 스포츠 학교, `Unternehmen`은 기업,
   `Sonstige`는 기타입니다.
4. 약칭, 등록 정보, 설립일, 웹사이트, 이메일, 전화번호, 주소 및 협회 식별 정보를
   알고 있는 범위에서 입력합니다.
5. `Speichern`으로 저장한 뒤 상세 기록을 다시 열어 확인합니다.

선택 사항을 모르면 비워 두십시오. 임의의 등록 번호를 만들지 마십시오. 조직 설정은
사용자 계정의 접근 권한을 자동으로 부여하지 않습니다.

### 상위·하위 조직 연결

전국 협회를 먼저 등록합니다. 지역 협회를 만들 때 전국 협회를 상위 조직으로
선택하고, 도장이나 클럽을 만들 때 해당 지역 협회를 상위 조직으로 선택합니다.
참조 선택기에서 실제 기존 기록을 선택해야 합니다. 이름만 입력해서는 연결되지 않습니다.

데스크톱의 `Struktur`에는 하위 조직이 표시됩니다. 추가 협회 소속은
`Verbandszugehörigkeit`에서 역할과 유효 기간을 지정합니다. 자기 자신 또는 자신의
하위 조직을 상위 조직으로 지정할 수 없습니다. 거부되면 같은 조직을 새로 만들기보다
기존 상위 연결을 확인하십시오.

`Abteilungen`에서 부서와 종목을, `Beiträge`에서 회비 그룹, 통화 및 주기를 관리합니다.
금액은 **센트 단위**입니다. EUR 25.00은 `2500`입니다. 이 값은 기초 데이터이며
자동 청구나 결제 지시가 아닙니다. 조직 기록에서 회원, 직책, 관계, 연락처, 주소 및
파일도 확인할 수 있습니다. 데스크톱과 포털의 일부 화면 구성은 다릅니다.

## 인물 상세 기록

### 인물 추가

1. `Personen`에서 기존 인물을 검색합니다.
2. 이름과 성을 입력하여 새 인물을 만들고 저장합니다.
3. 해당 기록 또는 `Akte öffnen`을 선택합니다.
4. 필요한 영역을 입력하고 각 영역을 저장한 후 이동합니다.

검색은 입력한 문자열을 기준으로 하며 대소문자를 구분합니다. 찾을 수 없으면 검색어를
줄이고 다음 페이지도 확인하십시오. 한 페이지는 최대 100개이므로 전체 목록과 같지
않을 수 있습니다.

| 화면 표시 | 내용 |
|---|---|
| Übersicht | 이름, 성 및 기본 식별 정보 |
| Persönlich | 생년월일, 호칭, 성별, 보호자 및 비상 연락처 |
| Kontakt | 용도를 표시한 전화번호와 이메일 |
| Anschriften | 용도를 구분한 주소 |
| Mitgliedschaften | 소속 조직, 회원 번호, 상태 및 기간 |
| Funktionen | 조직 내 직책과 유효 기간 |
| Beziehungen | 기타 조직·연락 관계 |
| Dateien | 증빙 파일; 인물 사진은 상단 고정 위치에 표시 |
| Eigene Felder | 데스크톱에서 권한이 있는 사용자 정의 필드 |
| Graduierungen / Prüfungshistorie | 무술 모듈 활성화 후 승급 및 심사 이력 |
| Dokumente / Dokumentvorlagen | 선택한 인물을 위한 문서 생성 |

날짜 입력은 운영체제 또는 브라우저 형식을 따릅니다. API와 기술적 내보내기에서는
`2026-09-08` 같은 ISO 날짜가 표시될 수 있습니다. 현지 형식이 표시되는 입력란에
다른 형식을 억지로 입력하지 마십시오.

작은 포털 화면에서는 `Aktenbereich`로 영역을 선택합니다. 데스크톱의
`Entwurf behalten und schließen`은 저장하지 않은 초안을 유지하며 점 표시가 나타납니다.
이는 **데이터베이스에 저장한 상태가 아닙니다**. 포털에서는 이동 전에 저장하거나
의도적으로 편집 내용을 취소하십시오. 미저장 초안은 백업된 데이터가 아닙니다.

## 회원 자격과 직책

인물 기록에서 `Mitgliedschaften → Neu anlegen`을 엽니다. 인물은 해당 기록으로
고정되며 조직을 직접 선택합니다. 회원 번호, 상태, 가입일을 입력하고 필요하면 회원
유형, 부서, 회비 그룹 및 탈퇴 정보를 추가합니다. 조직 기록에서 시작하면 조직이
고정되고 인물을 선택합니다.

종료일은 시작일보다 빠를 수 없습니다. `Aktiv`, `Ruhend`, `Beendet`는 각각 활동,
휴면, 종료 상태이며 로그인 계정의 활성 상태와는 다릅니다. 탈퇴 시 기존 회원 자격에
종료일과 사유를 기록하고 인물을 새로 만들지 마십시오. 자동 청구, 독촉, 계좌 자동
이체 및 법적 해지 통보기간 계산은 이 버전에 포함되지 않습니다.

`Funktionen`에는 지도자 또는 대표 같은 직책과 기간을 입력합니다. 직책 자체는
프로그램 권한을 부여하지 않습니다. 지도자 직책은 `martial.write` 권한을 대신하지
않습니다. 한 인물은 여러 회원 자격과 직책을 가질 수 있습니다.

## 사진과 첨부 파일

인물 사진 또는 조직 로고는 상세 기록 상단의 고정 이미지 영역에 지정합니다.
`Foto auswählen`, `Logo auswählen` 또는 `Foto / Logo hochladen`을 선택합니다.
PNG와 JPEG를 지원하며 화면에서 크기를 조정합니다. 너무 크거나 손상된 이미지는
거부될 수 있습니다. 새 대표 이미지는 해당 기록의 기존 대표 이미지를 대체합니다.

계약서, 증명서 및 기타 자료는 `Dateien` 또는 `Unterlagen und Dateien`을 엽니다.
`Datei hochladen`으로 파일을 선택하고 완료를 기다립니다. 파일 이름과 연결된 기록이
맞는지 확인합니다. 일반 파일 제한은 5 MiB, 즉 5 × 1,024 × 1,024바이트입니다.
용도를 알 수 있는 파일 이름을 사용하십시오. 비밀번호를 첨부 파일에 보관하거나
실행 모듈을 문서 업로드로 설치하지 마십시오.

파일 또는 `Herunterladen`을 선택하여 저장한 다음 알맞은 프로그램에서 엽니다.
업로드와 확인용 다운로드가 성공할 때까지 원본을 보관하십시오. 0.5.0에는 일반적인
삭제 화면이 없습니다. 잘못된 기록에 연결했다면 관리자에게 문의하십시오. 모든 파일
목록에서 파일 이름 검색이 제공되는 것은 아닙니다.

## 무술: 승급과 심사

관리자가 호스트에 네이티브 라이브러리를 설치하고 활성화해야 합니다. 이후 인물
기록에 `Graduierungen`과 `Prüfungshistorie`가 표시됩니다. 탭이 없다면 모듈 활성화와
서버 연결을 확인하고, 접근 거부 시에는 모듈 권한도 확인합니다.

승급 기록에는 종목·스타일, 1~30의 단계, 자유 명칭, 취득일 및 선택적인 심사위원을
입력합니다. 예를 들어 종목 `Taekwon-Do`, 단계 `8`, 명칭 `8. Kup`입니다. 이 숫자는
협회 전체에 공통인 급·단 순서를 정의하지 않습니다. 소속 조직의 승급 규칙을 따르십시오.

심사에는 종목, 목표 단계, 심사일, 결과, 심사위원 및 선택적인 비고를 입력합니다.
결과는 정확히 `passed` 또는 `failed`입니다. 심사를 저장해도 승급 기록이나 증명서가
자동 생성되지는 않습니다. 각각 별도로 처리하고 확인하십시오. 응시 자격 판정이나
심사비 처리도 자동화되어 있지 않습니다.

## 사용자 정의 필드

관리자는 데스크톱에서 기록 유형별 추가 필드를 정의할 수 있습니다. 텍스트, 정수,
소수, 불리언 및 날짜 유형을 지원합니다. 그룹별 필드 권한을 지정한 후 인물 기록의
`Eigene Felder`에서 값을 입력합니다.

쓰기 전용 권한에서는 현재 값이 보이지 않습니다. 빈 입력란이 기존 값이 없다는 뜻은
아닙니다. 필드 유형 변경 전에는 백업하고 값을 점검하십시오. 변환할 수 없는 값이
하나라도 있으면 전체 변경이 거부되어 부분 변경을 방지합니다. 현재 포털에서는 Core
사용자 정의 필드의 정의와 필드 권한을 관리하지 않습니다.

## 문서 템플릿과 보고서

관리자는 `Dokumentvorlagen`에서 제목과 일반 텍스트 본문을 작성합니다. 지원하는
자리표시자는 다음 세 가지뿐입니다.

```text
참가 확인서

{{given_name}} {{family_name}} 님의 참가를 확인합니다.
발급일: {{date}}
```

`{{member_number}}` 같은 추가 자리표시자는 거부됩니다. 템플릿은 실행 코드를 포함하지
않습니다. 대상 인물의 기록을 열어 수신자를 선택합니다.

데스크톱에서는 `Dokumente`의 저장된 템플릿에서
`Gespeicherte Vorlage als PDF öffnen`을 선택하고 저장 위치를 지정한 뒤 시스템 PDF
뷰어에서 확인합니다. 포털에서는 `PDF-Vorschau`를 사용합니다. 모바일 브라우저에서
PDF를 내장 표시하지 못하면 `PDF öffnen` 또는 `Herunterladen`을 사용하십시오.
배포 전에 이름, 날짜, 줄바꿈 및 문구를 검토합니다. 이메일 자동 발송은 제공되지
않으며 템플릿 날짜는 현재 ISO 형식입니다.

목록은 먼저 대상과 검색 조건을 선택한 뒤 `CSV exportieren` 또는
`Gefilterte Liste exportieren`으로 내보냅니다. 모든 페이지에 걸쳐 최대 5,000개를
포함할 수 있습니다. 내보내기 중에는 해당 목록의 동시 편집을 피하십시오. 스프레드시트에서
UTF-8과 쉼표 구분을 선택합니다. 수식처럼 보이는 값 앞의 작은따옴표는 보호 조치이므로
영향을 이해하지 못한 채 제거하지 마십시오. 빈 결과가 나오면 검색 조건과 권한부터
확인합니다.

## 표시 설정과 도움말

데스크톱에서 `Einstellungen → Ansicht → Darstellung und Farben`을 엽니다. 시스템
모드는 밝음·어두움 설정을 따릅니다. 대안으로 고대비를 포함한 다섯 색상 구성을 선택하거나
직접 색상을 지정할 수 있습니다. 포털의 `Einstellungen → Ansicht`에는 시스템,
밝음, 어두움, 숲, 자두색, 고대비가 있으며 자유 색상 지정 화면은 아직 없습니다.

관리자는 `Einstellungen → Startbildschirm` 또는 포털의 해당 설정에서 로그인 화면
이미지를 지정합니다. 이 이미지는 **로그인 전에도 공개**되므로 비밀 자료를 사용하지
마십시오. 인물 사진과는 별개입니다.

데스크톱의 `Hilfe → Nach Updates suchen`은 안정 버전 업데이트를 확인합니다.
비공개 저장소에는 접근 권한이 필요할 수 있습니다. 확인 실패는 최신 버전이라는 뜻이
아닙니다. 확인 기능은 업데이트를 설치하지 않습니다. 실제 업그레이드는 관리자와
운영 절차에 따라 진행하십시오.

## 계정 및 권한 관리

사용자를 만들고 그룹에 추가한 뒤 그룹에 역할을 연결하고 역할에 필요한 권한을
부여합니다. 연결 전체를 확인하십시오. 기본 읽기는 `records.read`, 회원 자격에는
추가로 `memberships.read`, 무술에는 추가로 `martial.read`가 필요합니다. 쓰기 권한은
필요한 경우에만 부여합니다. 원인을 모르는 오류를 해결하려고 일괄 `*` 권한을 주지
마십시오.

마지막 활성 관리자를 비활성화하거나 마지막 관리자 권한 연결을 제거할 수 없습니다.
비밀번호를 잃어버렸다면 운영 문서의 로컬 관리자 복구 절차를 사용합니다. 공개 관리자
초기화 API는 없습니다. 조직 내 직책과 보안 역할은 별개이며 사용자 정의 필드에는
별도의 그룹별 허용 설정이 필요합니다.

## 문제 해결과 일일 확인

| 증상 | 다음 조치 |
|---|---|
| 이름 입력 후 진행되지 않음 | 저장·생성 버튼과 오류 표시, 창 크기 및 설치 버전을 확인 |
| 변경 내용이 보이지 않음 | 기록과 호스트 모드를 확인하고 새로 고침 및 검색 조건 초기화 |
| 접근 거부 | 해당 역할, 필드 권한 및 모듈 권한을 관리자에게 확인 요청 |
| 다른 곳에서 기록이 변경됨 | 의도한 변경을 보관하고 다시 읽어 차이를 비교한 뒤 저장 |
| 저장 직후 네트워크 오류 | 재시도 전에 실제 저장 여부를 먼저 확인 |
| 모듈이 없음 | 호스트의 모듈 경로, 활성화 및 버전을 확인 |
| PDF가 열리지 않음 | 저장 파일과 시스템 뷰어 또는 포털의 `PDF öffnen` 확인 |
| 파일이 너무 큼 | 원본을 보관하면서 알맞은 크기의 사본 생성 |

업무 종료 전에 초안을 정리하고 중요한 변경을 다시 확인한 후 로그아웃합니다.
백업 감시와 복구 연습은 관리자의 업무입니다. 지원 요청에는 버전, 실행 모드, 시각,
수행 작업 및 오류를 포함하되 비밀번호, 토큰 및 불필요한 개인정보는 제외하십시오.
