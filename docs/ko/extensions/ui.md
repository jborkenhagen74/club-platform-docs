# 선언형 화면 확장

[시작 페이지](../README.md) · [개발](getting-started.md)

ABI 2는 자료형과 필드를 설명합니다. 데스크톱과 포털은 이를 **개인 기록**의
탭과 입력 양식으로 표시합니다. 임의 메뉴, 위젯 또는 스크립트를 매니페스트로
추가하지 않으며 조직 기록에 자동 부착하지도 않습니다.

자료형 `label`은 탭 제목, 필드 `label`은 입력 항목 제목입니다. `integer`는
정수, `date`는 ISO 전송 날짜입니다. 화면은 OS·브라우저 지역 설정을 따릅니다.
선택 항목임을 표시하고 값이 없으면 빈 문자열을 전송합니다. 기술 키는 번역하지
않습니다. 0.5.0의 매니페스트 label은 단일 문자열이며 다국어 번역 사전이 아닙니다.

읽기와 저장 때 권한을 다시 검사하므로 기록을 연 후에도 거부될 수 있습니다.
리비전을 유지하고 `409`는 비교 후 처리하십시오. 강제 덮어쓰기로 우회하지
마십시오. 보이는 탭은 쓰기 권한의 증거가 아닙니다.

인수 시험은 관리자 로드·활성화, 사람 열기, 필수 항목 저장과 재열기를 포함합니다.
잘못된 날짜와 업무적으로 허용되지 않는 값을 시험하십시오. 제한 역할로 읽기는
되지만 쓰기는 실패하는지 확인합니다. 두 화면과 좁은 창에서도 시험하십시오.
무술 모듈은 자유로운 등급 명칭과 1–30 단계 검증을 보여주지만 연맹 전체에
공통인 등급 체계를 규정하지 않습니다.
